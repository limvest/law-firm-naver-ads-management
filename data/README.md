# data

- `keywords.json`: 실제로 수집한 사건명 약 2만 8천 건과 관측 기록입니다. 출처로 쓴 법률사무소 이름과 주소는 가상 값으로 바꿨습니다. 맨 끝의 `mock…`/`가상…` 항목 몇 개는 테스트용 가상 사건입니다.
- `harvest-sources.json`: 수집 소스 설정이며, 소스 이름과 주소는 가상 값입니다.
- 수집 원문(inbox), 수집 상태, 경쟁 키워드 집계, 트래픽 기록은 포함하지 않았습니다.

사건명은 공개 웹에서 수집한 검색 키워드이며, 해당 업체가 사기라는 판단이나 주장이 아닙니다.
